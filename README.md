# Wick's UI

A full interface for World of Warcraft: Forever. Action bars, unit frames,
party and raid frames, nameplates, buffs, chat, minimap, tooltips, info
panels, a threat meter and the game's own windows, all drawn in one look,
and every part of it optional.

Pick a look and everything changes with it: Wick Modern, Wick OG and six
more, each with its own shapes, fonts and colours. Wick's Bags and the
class kits follow the same look.

    /wui              settings
    /wui move         unlock frames to drag them
    /wui kb           bind keys by pointing at a button
    /wui install      run the setup again
    /wui reset        put every frame back where it started

**What it replaces**

- Action bars, stance and pet bars. Your existing keybinds carry over, and
  spells on your bars move up to the new rank when you train it.
- Player, target, focus, pet, boss, party and raid frames. The raid frames
  carry the healer pieces: a dispellable debuff in the middle, your own
  heals over time in the corners.
- Nameplates with target and focus markers, class marks, an execute
  highlight and threat colours.
- Buffs, chat, the minimap (with other addons' minimap buttons gathered
  into one flyout), tooltips, info panels, and the XP and reputation bars.
- The game's windows: character, spellbook, talents, professions, map,
  mail, vendors, trainers, the bank, friends, guild, the group finder,
  settings and more, dressed to match. The damage meter and swing timers
  too.

**What it adds**

- A threat meter, a personal threat bar that warns before you pull, and
  frames that glow with threat.
- A raid marker bar, a quieter error line in combat and an AFK screen.
- Picture settings the game has but leaves out of its options, and fuller
  combat text controls.
- The comforts from Wick's Comforts built in: tooltips, looting, the
  vendor, quests and the camera, each one off until you turn it on.
- Profiles, a mover for every frame, and a setup on first login that asks
  about the addons you already run instead of fighting them.

Made for this client's rules. Health and combat numbers are shown the way
the client hands them over and are never read, so nothing breaks in a
fight, and nothing is written into the game's own frames.
